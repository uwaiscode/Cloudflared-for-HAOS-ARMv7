# Cloudflared for HAOS ARMv7

Remote access for your Home Assistant (iHost/Orange Pi) via Cloudflare Zero Trust Tunnel.

## 🛠 Installation
1. Add this repository to your Home Assistant Add-on Store:
   `https://github.com/uwaiscode/Cloudflared-for-HAOS-ARMv7`
2. Install **Cloudflared Tunnel for ARMv7**.
3. Go to the **Configuration** tab.
4. Paste your **Tunnel Token** from the Cloudflare Zero Trust Dashboard.
5. Click **Save** and **Start**.
